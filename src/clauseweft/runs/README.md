# runs · 执行尝试、预算与恢复

对应 **F07 / A08、A09、A10**，支撑 F02 的可核对回退和 F03 的真实并行。执行入口为 `Runs(store, catalog).work_once()`，每个 worker 循环领取一个就绪节点。

## 从哪里改

| 模块 | 职责 |
|---|---|
| [engine.py](engine.py) | `Runs` 的公共操作，包括创建、预览、worker 循环、暂停、恢复、审批和返工 |
| [requests.py](requests.py) · [materials.py](materials.py) | 校验任务、预算与材料，组装模型消息，构造预览和真实派发共用的路由快照 |
| [state.py](state.py) | 在调用方事务中读取运行、节点及余额，刷新依赖，生成运行详情 |
| [leases.py](leases.py) | 原子领取就绪节点、续租，回收未派发尝试，标记已派发但过期的尝试 |
| [dispatch.py](dispatch.py) | 复查输入和权限，在预算与并发限制内分配模型，保存意向、上下文及预留 |
| [receipts.py](receipts.py) | 校验网关回执、计算费用、处理重试与人工对账 |
| [results.py](results.py) | 读取模型结果，验证复杂任务分工和工具决策，在回执事务内更新执行图 |

网关请求在派发事务提交后发出。收到答复时，`finish_attempt` 先核对当前尝试，只有仍有发布权的成功回执才进入 `publish_result`。原始答复引用、账目和节点状态在回执事务中登记。

## 运行与账目

runs 拥有运行、尝试、调度租约关联、取消请求、预算预留/结算/待核对条目与历史事件。workflow 描述哪些任务可执行。领取时创建尝试并取得租约；派发时用新的短写事务复查租约、输入、取消状态、路由资格和预算，把预留与派发意向绑定到同一尝试。事务提交后才经 HTTP 交给 [gateway](../gateway/README.md)，并附已核实的网关配置 ETag。限流、超时及无回执分别记账，新的调用必须有独立尝试。单次运行固定币种，费用以整数微单位记录，区分估算、实际和未知。

| 运行操作 | 输入与结果 | 主要失败 |
|---|---|---|
| 预留并开始尝试 | 运行、任务和输入摘要、幂等键、端点版本与费用上界 → 尝试 ID 和预留记录 | 余额不足、状态过时或硬预算下上界未知；不启动请求 |
| 记录完成与对账 | 尝试 ID、实际端点与回执、用量及完成状态 → 可发布产物引用和账务变更 | 发出后应答未知，维持待核对；取消后迟到回执仅供历史和账务使用 |
| 取消或恢复 | 运行 ID、负责人指令、预期状态、当前快照 → 取消标记或可恢复分支 | 已成功且输入未变的分支复用；可能已收费的未知调用需明确处置后重试 |

`start` 和 `claim` 登记运行并领取节点，`dispatch` 预留额度后派发，`finish` 记录结果。`cancel` 关闭新的派发与发布权，`resume` 从有效检查点继续。已取消的终态运行需要重新创建。

**验收例**：余额 1.00，两分支各需 0.70，同时领取也只能有一路获得预留。其响应超时并重启时，保留历史尝试和待核对金额。负责人取消运行后，迟到回执可结算费用，但不会发布补丁或解锁后续工作。

关联设计：[模块与依赖](../../../docs/04-概要设计.md) · [接口与事务](../../../docs/05-详细设计.md)。

在运行页的尝试记录中，`decision.selected_endpoint` 表示本次派发端点。如果独立模型分组或限流回退改变了排序首选，`ranked_first_endpoint` 会保留原首选。可按 `independent_group` 核对同组各路的模型身份，按 `rate_limited_endpoints` 查看该分支在当前世代已遇到限流的端点。例如 A 限流后改选 B，第二次派发会同时记录首选 A、实际端点 B 和限流列表中的 A。

平台按派发版本的价目与有效 token 回执结算，负责人可以通过 `reconcile` 提交实际账单、操作人及依据来调整金额。若提供方收费未知，或请求已发出后失去响应，预留继续占用预算。网关在外发前明确拒绝的请求释放预留。向已固定端点发送的尝试失败时等待负责人处理。自动模式遇限流最多尝试三次，每次均复查冻结版本约束、身份归属和余额。


收到被截断、过滤或空白的模型答复时，该次请求保留调用回执和原文，节点进入待处理，依赖节点继续等待。只有人工操作才会再发请求。普通任务可在“重新生成 → 本次执行设置”调整输出上限与预算，再产生独立的尝试和账目；截断的片段可在原任务的“调用与费用 → 路由与回执”查看。若端点配置的上限已经用尽，请缩小任务范围或选择能容纳答复的端点。
